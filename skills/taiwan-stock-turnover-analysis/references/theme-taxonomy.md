# 題材對照表（台股）

此檔案提供常用題材分類，供成交值排行資料做快速分群。若同時命中多題材，預設以「主要業務/市場慣用分類」為主，次要題材列為備註。

## 半導體

- 關鍵字：晶圓、IC 設計、封測、先進封裝、EDA、IP
- 常見子題材：CoWoS、HPC、車用半導體

## AI / 伺服器

- 關鍵字：AI、GPU、伺服器、資料中心、雲端
- 常見子題材：AI 伺服器組裝、機殼、電源、高速傳輸

## 散熱

- 關鍵字：散熱、均熱板、熱導管、風扇、液冷

## 網通 / 光通訊

- 關鍵字：交換器、路由器、光模組、800G、CPO

## 重電 / 電力基建

- 關鍵字：重電、變壓器、電網、儲能、電力工程

## 綠能 / 能源

- 關鍵字：太陽能、風電、儲能、氫能、節能

## 航運 / 物流

- 關鍵字：貨櫃航運、散裝、航空貨運、港口

## 生技 / 醫療

- 關鍵字：新藥、醫材、檢測、CDMO、醫療服務

## 金融 / 保險

- 關鍵字：銀行、證券、金控、壽險

## 內需消費 / 通路

- 關鍵字：零售、餐飲、觀光、電商、百貨

## 建材 / 營建

- 關鍵字：營建、建設、水泥、鋼構、不動產

## 汽車 / 電動車

- 關鍵字：電動車、車用零組件、充電樁、車電

## 題材映射優先序

1. 優先使用資料原始產業欄位。
2. 無產業欄位時，使用股票名稱關鍵字比對。
3. 若多題材衝突，採「市場主流敘事」優先（例如 AI 伺服器 > 一般電子零組件）。
4. 無法判定時，標記「其他/待分類」，不得硬分類。
