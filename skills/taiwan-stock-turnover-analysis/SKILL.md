# 台灣股市成交值排行榜專業分析

## 快速流程

1. 載入使用者提供的 `.xlsx`，確認欄位是否包含：代號、名稱、股價、漲跌幅、趨勢、外資買賣、投信買賣、融資增減（允許缺欄但要註記）。
2. 先做資料清理：欄位標準化、數值化（移除 `%`、逗號）、缺值填補策略（預設為 `0` 或「無資料」）。
3. 將個股映射到題材（AI、半導體、伺服器、散熱、重電、航運、生技等）。
4. 產出三層分析：
   - 市場層：最強/轉弱題材與資金集中度
   - 題材層：題材內強勢股、籌碼一致性、延續性
   - 個股層：短線續強機率與風險註記
5. 依使用者需求輸出：摘要版、投資委員會版、或 Word 報告版。

## 欄位正規化規則

- 同義欄位要合併：
  - `外資買賣超`、`外資` -> `foreign`
  - `投信買賣超`、`投信` -> `investment_trust`
  - `融資增減`、`融資` -> `margin_change`
  - `漲跌幅%`、`漲跌幅` -> `pct_change`
- 數值欄位一律轉為可計算格式。
- 若缺少 `foreign` 或 `investment_trust`，禁止輸出「雙主力確認」結論，改為「資料不足」。

## 題材分析標準

執行題材分類時，優先使用 `references/theme-taxonomy.md` 的對照。若檔案中已有「產業」欄位，先採該欄位，再以名稱關鍵字補強。

每個題材至少輸出：

- 題材股票數
- 題材平均漲跌幅
- 題材總外資買賣超
- 題材總投信買賣超
- 題材總融資增減
- 題材綜合熱度分數（0-100）

熱度分數建議權重（可依使用者指定調整）：

- 價格動能 35%
- 成交/關注度 25%
- 外資與投信籌碼 30%
- 融資變化 10%

## 機構/華爾街風格模型（預設）

當使用者要求「華爾街模型選股」、「機構法人模型」、「短期續漲機率高」時，使用以下框架並揭露分數來源。

### MFIM-4 因子

- **M (Momentum)**：漲跌幅、趨勢欄位
- **F (Flow)**：外資、投信買賣超
- **I (Imbalance)**：外資與投信是否同向、是否連續偏多
- **M (Margin)**：融資增減方向是否健康（價漲融資暴增視為風險）

### 輸出規則

- 產出 Top 名單（預設 Top 10）與候補名單（預設 10 檔）。
- 每檔需附：
  - 總分與四因子分
  - 入選原因（2-3 點）
  - 風險警示（至少 1 點）
- 不可使用保證語氣（例如「一定上漲」）。

## 雙主力確認與籌碼判讀

「雙主力確認」定義：`foreign > 0` 且 `investment_trust > 0`。

進一步分級：

- A 級：雙主力同買 + 股價上漲 + 融資未失控
- B 級：雙主力同買 + 股價整理
- C 級：僅單一法人買超或資料不完整

若使用者要求「籌碼分析」，至少提供：

- 雙主力檔數占比
- 題材別雙主力分布
- 「雙主力 + 趨勢轉強」交集清單

## 報告輸出格式

### A. 簡報式摘要（短版）

1. 今日市場主軸（3 點內）
2. 熱門題材排行（前 5）
3. 法人共識名單（前 5）
4. 風險與觀察點（2-3 點）

### B. 專業報告（長版）

1. 資料來源與欄位完整度
2. 市場資金結構與題材輪動
3. 題材統計表
4. MFIM 模型選股清單
5. 雙主力確認清單
6. 風險揭露與情境推演（樂觀/中性/保守）

### C. Word 報告產製要求

- 使用正式商務語氣（繁中）。
- 含標題、日期、摘要、章節編號、結論與風險揭露。
- 表格欄位名稱固定且一致（避免同欄位多種叫法）。

## 品質門檻

- 明確標示分析基準日與資料筆數。
- 缺漏欄位要在前言先揭露。
- 所有結論需可追溯到欄位或分數，不可只給主觀判斷。
- 若使用者有指定投資週期（當沖/波段），要調整語言與排序依據。
